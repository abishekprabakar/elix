Give any agent a wallet it cannot overspend.

Elix runs as an MCP server, so Claude Code, Claude Desktop or any MCP client can route its purchases through it. The agent gets seven tools to ask, check and explain. It gets no tool to approve or to pay, and the gateway holds the only key.

Read the source on GitHub

Terminal
# add Elix to Claude Code as the Scout agent
claude mcp add elix --env ELIX_AGENT_TOKEN=tok_scout \
  -- python -m elix.mcp_server

# then ask Claude to buy something
